Подключение Mac + Windows

Рекомендуемая схема (Dell U2724DE):

MacBook ──USB-C/TB4──► Thunderbolt upstream (видео + 90 W + USB) Windows ──DisplayPort──► DP IN Windows ──USB-B───────► KVM (общие клавиатура и мышь) Переключение: меню KVM на мониторе

Кабели: USB-C/TB4 0.8–1 м · DisplayPort 1.4 · USB A–B для KVM.

Не брать для офиса 8+ ч/день: OLED (Dell S3225QC) — риск выгорания от статичного интерфейса, несмотря на красивый белый корпус.
